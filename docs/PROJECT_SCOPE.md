# Project Scope

## In Scope

- Pendataan alumni
- Authentication
- Profil alumni
- Admin panel
- Verifikasi
- Search
- Filter
- Statistik
- Export
- Pengelolaan user

## Out of Scope

- Chat
- Social feed
- Marketplace
- Learning management system
- Payment gateway
- Mobile native app
- Microservices
- Realtime infrastructure

## Technology Constraint

MVP menggunakan satu aplikasi Laravel.

Infrastructure tambahan hanya boleh ditambahkan berdasarkan requirement dan hasil pengukuran.
